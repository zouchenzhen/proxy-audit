RESPONSIBLE USE

使用、隐私与安全边界

Proxy Audit 是只在本机运行的节点连通性与出口 IP 质量检测工具。请仅检测本人所有、本人管理或已经取得明确测试授权的节点。

使用边界隐私流向安全部署第三方许可返回面板

负责任使用

勾选授权确认不等于自动取得授权，也不代表任何用途当然合法。用户仍需遵守所在地法律、网络接入规则、单位制度、合同和第三方服务条款。

允许用途

  • 本人节点或已获明确授权资产的质量检测；
  • 教学、研究、实验室或企业内部的合规运维；
  • 在最小必要范围内生成和保存脱敏结果。

禁止用途

  • 未经授权使用、扫描、分享、售卖或推广他人节点与订阅；
  • 绕过访问控制、监管、付费限制、平台风控或地域限制；
  • 入侵、撞库、拒绝服务、凭据窃取、恶意扫描或掩盖违法活动。

完整的责任边界、发布边界和贡献要求见仓库 COMPLIANCE.md。该说明不是个案法律意见。

隐私与数据流向

项目没有官方云端账户、广告或遥测。节点凭据只用于内存和一次性内核配置，不进入结果文件；API Key 在 Windows 下使用当前用户 DPAPI 加密，完整 Key 不会回传浏览器。

检测并非完全离线：订阅服务器会收到拉取请求；ipify 请求经待测节点发出；启用的 IP 情报商会收到被查询出口 IP 和相应 API Key；可选测试端点会看到节点出口 IP 与常规网络元数据。

详细保存位置、第三方流向和删除方法见 PRIVACY.md。

安全部署

  • 面板只应监听 127.0.0.1，不要用端口映射、反向代理或 Tunnel 暴露到公网；
  • 不要在 Issue、PR、截图和日志中提交真实订阅、UUID、密码、Key 或出口 IP；
  • 只使用可信内核，保留下载校验，并限制项目与结果目录的本机访问权限。

漏洞请按 Security Policy 私下报告。
